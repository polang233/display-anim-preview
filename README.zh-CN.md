# Java 逐帧显示动画

这是 Blockbench 插件 **Java Display Animator** 的公开源码仓库。

## 构建与测试

```bash
npm ci
npm test
npm run typecheck
npm run build
```

构建结果位于 `dist/display_anim_preview.js`，图标位于 `dist/icon.png`。

## 本地安装

在 Blockbench 中选择“文件 → 插件 → 从文件加载插件”，然后选择
`dist/display_anim_preview.js`。
