# Contributing

Thank you for your interest in Java Display Animator. Contributions are welcome through a controlled
Fork and Pull Request workflow. This repository does not grant an open-source license.

## Before You Start

Small bug fixes, documentation corrections, and narrowly scoped improvements may be submitted
directly.

New features, major refactors, export-format changes, compatibility changes, or other substantial
work must be discussed with the maintainer before implementation. Prior discussion does not
guarantee that a contribution will be accepted.

## Contribution Workflow

1. Fork this repository.
2. Create a dedicated branch in your own Fork.
3. Keep the change focused and avoid unrelated modifications.
4. Run the relevant tests and describe the results.
5. Submit a Pull Request to this repository.

Repository write access is not required. The maintainer may request changes, rewrite parts of a
contribution, decline it, or close it. Acceptance and merging remain at the maintainer's discretion.

## Modified Versions and Project Identity

Permission to modify the project is granted only as necessary to prepare a proposed contribution in
a GitHub Fork.

Without prior written permission from the copyright holder, you may not:

- publish, distribute, repackage, or release a modified version of the source code or compiled
  plugin;
- upload modified builds as GitHub Releases or distribute them through other websites, plugin
  repositories, groups, or download services;
- use the name **Java Display Animator**, its icon, or similar branding to present a modified version
  as official, endorsed, or maintained by this project;
- imply that a Fork or derivative version is an official release of this project.

## Original Work and Third-Party Content

By submitting a Pull Request, you confirm that:

- the contribution is your own original work, or you have the legal right to submit it;
- any third-party code, assets, or other materials are clearly identified with their source and
  applicable terms;
- the contribution does not knowingly infringe another person's copyright, license, trademark, or
  other rights.

Contributions containing undisclosed or incompatible third-party material will not be accepted.

## Permission for Each Contribution

Each Pull Request must include an explicit written authorization for that specific contribution.

By checking the authorization statement in the Pull Request template, you give the copyright holder
permission to review, reproduce, modify, integrate, compile, distribute, and publish the accepted
contribution as part of Java Display Animator and its related builds.

This permission applies only to the contribution contained in that Pull Request. It does not grant
you or other users permission to independently distribute or publish modified versions of the
project.

You retain ownership of your original contribution. A contribution will not be merged if the
required authorization is missing.
